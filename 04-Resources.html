منابع (به‌جز Microsoft Learn)

لینک‌ها رو قبل از استفاده چک کن؛ بعضی ممکنه جابه‌جا شده باشن.

تمرین تعاملی

  • Kusto Detective Agency (detective.kusto.io): بهترین تمرین KQL به شکل معما.
  • DAX Puzzle / DAX Patterns (daxpatterns.com): الگوهای آماده‌ی DAX.
  • SQLBolt / LeetCode SQL / StrataScratch: تمرین T-SQL و window functions.
  • Fabric Samples (GitHub: microsoft/fabric-samples): نمونه Notebook و Pipeline رسمی.
  • Fabric Toolbox (GitHub: microsoft/fabric-toolbox): ابزارها و اسکریپت‌های کاربردی.

مقالات و آموزش عمیق

  • SQLBI (sqlbi.com) و DAX Guide (dax.guide): مرجع DAX و VertiPaq.
  • Delta Lake docs (docs.delta.io): MERGE، OPTIMIZE، time travel، constraints.
  • Apache Spark docs: join strategies، AQE، tuning.
  • Kusto (KQL) reference در docs مایکروسافت (به‌عنوان reference، نه آموزش).
  • بلاگ‌ها: Data Goblins، Fabric Community blog، Sandeep Pawar (Fabric Spark/Semantic Link)، Kevin Chant (ALM/Git).
  • یوتیوب: Guy in a Cube، SQLBI، Advancing Analytics، Pragmatic Works.

آزمون تمرینی

  • MeasureUp: آزمون‌های تمرینی رسمی (پولی).
  • Whizlabs / Udemy: آزمون‌های تمرینی. کیفیتشون متغیره؛ سوالات قدیمی رو با دقت بخون.
  • Microsoft Learn Practice Assessment: رایگان است ولی خواسته بودی بیرون از Learn باشه، فقط برای تایید نهایی.

ابزارهای مفید روی کامپیوتر
